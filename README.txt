FUTTAGE - Editor de Vídeo para YouTube
======================================

Versão: 2.0.0
Data: 07/09/2025

DESCRIÇÃO:
O Futtage é um editor de vídeo simples e eficiente para concatenar,
cortar e fazer upload de vídeos diretamente para o YouTube.

REQUISITOS:
- Windows 10 64-bit ou superior
- Conexão com internet para upload
- Conta Google/YouTube

PRIMEIROS PASSOS:
1. Execute o Futtage.exe
2. Faça login com sua conta Google
3. Selecione os vídeos para editar
4. Configure e faça upload para o YouTube
